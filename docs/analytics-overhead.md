## What this does and does not say

- The load generator shared a machine with the service, so the two competed for CPU.
  Turning the feed on adds a thread to the same contended machine, so any difference
  here includes that contention and is not a measurement of the feed alone.
- A difference smaller than the spread across runs within either set is not a signal.
- This is a few minutes of synthetic load on one developer machine. It supports a
  statement about these runs and nothing wider: no capacity figure, no per-request cost,
  and nothing about behaviour over time.
- The offered rate never saturated the service, so this compares two unsaturated runs.
  It says nothing about the feed's cost at a rate high enough to queue.
